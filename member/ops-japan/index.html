身份 / PROFILE

我叫名城悠真，日籍华裔，现任株式会社NSR董事长、AAT集团日本地区CEO，和君商学院19期出海班学员、同时担任日本损害保险协会神奈川分会理事、日本大连商会理事。长期深耕日本金融保险与中企出海服务领域，致力于为中国企业落地日本提供一站式资源对接与合规运营支持。

专业背景与核心能力 / EXPERTISE

我拥有日本国家二级金融理财师（FP）资格，在日本金融保险行业从业多年，对日本当地的税务体系、法务合规、保险经纪及财富管理有着系统而深入的理解。作为株式会社NSR的董事长——这是一家位于东京的老牌保险经纪公司——我主导公司的战略规划与业务拓展，服务客户覆盖在日华人企业、中资驻日机构及日本本地企业，提供包括企业风险评估、保险方案定制、员工福利规划、税务筹划咨询在内的综合金融服务。

在长期实践中，我积累了丰富的中日跨境业务经验，熟悉中企进入日本市场时常见的合规陷阱与运营痛点，能够从金融、税务、法务三个维度为企业提供前置性风险预警与落地解决方案。

中企出海实战案例 / CASE STUDY

2026年2月，我主导并协助AAT集团（一家专注于建筑材料技术咨询的企业）成功完成日本市场落地。从前期的市场调研、主体设立、税务登记，到团队组建、业务渠道搭建、本地合作伙伴对接，我全程参与并统筹推进，帮助AAT集团在较短时间内完成了从0到1的日本市场布局。基于对项目的深度参与和对日本建材行业的理解，我同时兼任AAT集团日本地区CEO，全面负责其在日业务的运营管理与战略落地。

这一案例不仅验证了我在中企出海服务领域的实操能力，也积累了建筑材料、技术咨询等细分行业在日落地的宝贵经验，可为后续同类企业提供可复用的落地路径与资源网络。

社会职务与资源网络 / NETWORK

此外，作为和君商学院19期出海班学员，我与中国国内一批有志于全球化布局的企业家保持着深度的学习与交流，能够及时把握中国企业出海的最新趋势与需求变化。

服务理念与未来方向 / VISION

我始终认为，中企落地日本的核心挑战不仅在于合规与运营，更在于对日本商业文化、社会规则和人脉网络的深度融入。基于自身日籍华裔的双语双文化背景，以及在金融保险、行业协会、侨社组织三个维度的资源积累，我希望成为中国企业进入日本市场的“超级连接器”——不仅提供专业的金融与合规咨询，更帮助企业打通本地渠道、对接合作伙伴、融入商业生态。

未来，我将继续聚焦中企出海日本服务，重点关注建筑建材、新能源、消费品牌、科技服务等领域，与更多有志于开拓日本市场的中国企业携手，实现从“落地”到“扎根”再到“成长”的全周期陪伴。
